# AGENTS.md

## What this repo is

Personal dotfiles. The payload is `src/`, symlinked into `$HOME` by `install.sh`.
Root files (`mise.toml`, `.pre-commit-config.yaml`, `.github/`) are repo tooling and are
**not** installed. Editing `src/...` changes the live dotfile only if this checkout is the
symlink target (README clones to `~/.dotfiles`); new files need a fresh `install.sh` run.

## Install layout (`install.sh`)

- `src/.<name>` file → symlink to `$HOME/.<name>`.
- `src/<dir>/` (e.g. `.config`, `.bashrc.d`) → `mkdir -p $HOME/<dir>`, then each child is
  symlinked into it.
- `install.sh -f` overwrites existing targets; without it `ln` fails on collisions.
- Vim plugins come from the `VIM_PLUGINS` array in `install.sh`, cloned to
  `~/.vim/pack/plugins/start/`.

## Commands (mise task runner)

- `mise run pre-commit` → `pre-commit run --all-files --color always`.
- `mise run bump-version:patch|minor|major` → bump-my-version updates `VERSION`, commits, and
  tags `vX.Y.Z`. Don't hand-edit `VERSION`.
- `mise run git-push` → `git push --follow-tags origin HEAD`.

## Gotchas

- `src/.config/mise/config.toml` is the user's *global* mise config (installed to
  `~/.config/mise/`), not this repo's. Repo tools and tasks live in root `mise.toml`.
- `.copier-answers.common.yml` is generated by Copier; the file says NEVER EDIT MANUALLY.
- Linting: pre-commit runs `yamllint --strict` (root `.yamllint.yaml`: 2-space indent, 120
  cols, `---` document start required except `.copier-answers*.yml`), `shellcheck`, and
  whitespace/hygiene hooks. CI (`.github/workflows/pre-commit.yml`) runs it on PRs and `main`.
- Markdown config is `src/.markdownlint.yml` (installed as a dotfile, not a root config; not
  run by pre-commit or CI): line length 100, ATX headings, dash lists.
- `**/.bashrc.d/mise.bash` is Ansible-managed and gitignored; don't create or commit it.
- Commit style is Conventional Commits with scopes, e.g. `chore(mise):`, `feat:`,
  `chore(deps):`.
